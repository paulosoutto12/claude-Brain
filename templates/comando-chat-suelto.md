# Comando para guardar chats sueltos

Copiá y pegá esto al final de cualquier chat de Claude Desktop que **no** esté dentro de un Project:

---

Guardá esta conversación en mi vault de Obsidian usando las herramientas MCP de Obsidian disponibles.
Resumen breve + puntos clave (no transcripción completa). Detectá tags
relevantes, creá la nota en Claude/AAAA-MM/ con frontmatter de tags y
fecha. Si existe un hub relacionado en Temas/, agregale un link a esta
nota nueva; si no existe, creá el hub.

---

## Variante: transcripción completa

Si preferís guardar la conversación completa en vez de un resumen, reemplazá la primera línea por:

```
Guardá esta conversación completa (transcripción íntegra, no resumen) en mi
vault de Obsidian usando las herramientas MCP de Obsidian disponibles...
```
